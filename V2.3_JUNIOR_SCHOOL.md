# OpenLab v2.3 — Jr. OpenLab school studio (preview)

## Entry point
- In the existing authenticated OpenLab, use the **Jr. OpenLab** pill in the top navigation, the left-sidebar Jr. card, or the home dashboard banner.
- Route: `/junior` — a standalone full-width school workspace. **Back to Research** returns to `/`.
- Uses the same existing AuthGate and Supabase project configuration. No migration or new environment variable is required for these particular school features.

## Included now (working starter activities)
1. **Element Studio:** 118 clickable periodic-table elements. Supports search and atomic number quiz. First 20 have correctly populated, explicitly simplified Bohr electron shells and introductory valency information. More advanced electronic configurations are intentionally not guessed.
2. **Molecule Workshop:** drag/drop or tap to add/remove atoms; identify H2O, CO2, NaCl, MgO and O2 from composition; explanatory bond/ionic nature; introductory schematic diagrams. This is not a chemically general 3D or reaction engine.
3. **DNA Discovery:** custom A/T/G/C reference sequences of up to 12 bases, interactive drag/drop or tap completion of complementary strand with feedback, illustrated DNA helix; link to existing advanced molecular biology workbench.
4. **Light & Reflection:** incident angle slider, ray geometry and reflected angle, predictive quiz with immediate explanation.
5. Grade selection for Classes 9–12 and subject selection for Chemistry/Biology/Physics, with a curated preliminary content roadmap. Currently planned topics are visibly labeled; this is NOT a complete official NCERT index.
6. English and Traditional Chinese (Taiwan) interface controls, including starter lab content, for PC and tablet.
7. Local per-profile science journal and activity completion indicators. The browser key includes workspace and profile IDs to avoid a global browser-wide note key.

## Limitations / work before public launch
- **Not complete Class 9–12 NCERT coverage.** Do not market this preview as the complete syllabus. Align to the specific current NCERT edition and create original questions or secure appropriate permissions.
- **Not a general 3D editor.** HD SVG diagrams and interactive controls are included; full manipulable 3D simulations and most chapters are future work.
- **Junior journal is local only**, not Supabase-synced across devices; clearing browser storage removes it. Existing research workspace data/synchronization is unchanged.
- As noted in previous project reviews, the core app needs a comprehensive per-account browser-state isolation and RLS security audit before opening student registrations at scale.
- Privacy, consent, safeguarding and access control require review before supporting minors at scale.
- Tablet drag/drop has a tap fallback; verify on actual iPads/tablets.
- General professional workspaces (chemistry, molecular biology, notebook) were preserved as-is.

## Technical notes
- Root shell switches to an isolated full-width Jr. workspace for `/junior`, retaining existing authentication and sync services.
- Source: `components/junior/JuniorSchool.tsx`, `components/junior/school-data.ts`, `app/junior/page.tsx`, plus styling appended to `app/globals.css`.
- No additional npm dependencies.
- Use your existing Vercel project and existing Supabase URL/publishable key.
- The current environment did not permit installing npm dependencies, therefore a full production Next.js build and live browser QA could not be completed here.

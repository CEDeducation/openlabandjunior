# OpenLab v2.2 — Interface and chemistry viewer update

Built on the complete v2.1 source. No change to Supabase project, migration schema or credentials.

## Changes
- Top-bar interface language selector: English / 繁體中文（台灣）. Saves choice in localStorage (`openlab.interface.locale.v1`).
- Translated core navigation, toolbar and selected chemistry terms with human-authored Taiwan Traditional Chinese strings. Scientific identifiers and user-authored notebook content are deliberately not auto-translated.
- 2D RDKit depiction: replaced transform/layout implementation; 25%–800% zoom, zoom buttons, wheel, pan with pointer drag (including tablet), Fit and expanded view; Escape exits expanded view. CSS override prevents legacy image sizing rules from disabling zoom.
- Improved readability for the chemistry input/result area and controls.
- Desktop and tablet remain prioritized; mobile is not a product target for this update.

## Test status
- `node scripts/scientific-regression.mjs`: PASS.
- npm dependency installation could not finish in this execution environment; full Next.js build and actual browser interaction are **not** claimed verified.
- Translation is intentionally **partial**, not yet a complete, professionally proofread localization of all tool descriptions, help pages, and rare-state error messages. The dropdown works across the app for supported interface strings. Additional routes should be localized with `lib/i18n.ts` and direct component translations in future increments.

## Deploy
Upload the contents of this folder to the existing GitHub repository and deploy on Vercel using existing `model2` Supabase environment variables. Do not create a new Supabase project.
